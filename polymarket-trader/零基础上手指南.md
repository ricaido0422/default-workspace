# 零基础上手指南（不用命令行）

适用对象：电脑上没装 Python、不会用命令行的用户。

---

## ⚡ 最快路径：什么都不用装（推荐先看这里）

**这个文件夹里已经自带了一套 Python 和全部依赖**，不用你自己下载安装 Python，也不用联网装任何东西。

### 就两步

1. 双击 **`1-start-service-bundled.bat`**（注意文件名里带 **`-bundled`**）
2. 等大约 10 秒，浏览器打开 **<http://localhost:8765>**

看到界面就能用了。用完直接关掉那个小黑窗，或者双击 `2-stop-service.bat`。

> ⚠️ **别双击错了**：文件夹里还有一个 `1-start-service.bat`（**没有** `-bundled`），
> 那是备用路径，走的是你自己电脑上的 Python。电脑没装 Python 的话双击它会报
> `Python not found on PATH`。**认准带 `-bundled` 的那个。**

> 💡 这个 `.bat` 用的是文件夹里自带的 `Python312\`，跟你电脑上装没装 Python 完全无关。
> 整个文件夹可以直接拷到 U 盘或别的电脑上，拷过去照样双击就能跑。

### 接下来怎么配？

界面打开后还不会自动跟单，需要配钱包和策略。跟着 [使用指南](使用指南.md) 的
「第 3 节：五步配好自动跟单」做，10 分钟配完。配好后可以用仪表盘底部的
**🧪 链路自检** 一键验证，不用干等真实交易。

## 备用路径：用你自己电脑上的 Python

如果你本来就想用系统里已有的 Python（比如要自己改代码、装别的包），走这条路。

### 第一步：安装 Python（只做一次）

> 这一步是最关键的，**有一处勾选千万别漏**。

1. 打开浏览器，访问 <https://www.python.org/downloads/>
2. 点黄色的 **「Download Python 3.12.x」** 按钮
3. 下载完成后，双击安装包
4. **安装界面第一屏，底部有一个复选框 `Add Python to PATH`，必须先勾上它！**
   （漏了这一步后面会报「Python not found」，这是最常见的失败原因）
5. 点 **「Install Now」**，等待完成
6. 安装结束后，**重启一次电脑**（让环境变量生效）

> 记住：第一屏最下面那个复选框，默认是**没勾选**的，一定要手动勾。
> 如果找不到，就找界面上任何带有 "Add Python to PATH" 字样的选项，勾上再继续。

> ⚠️ **注意**：如果电脑上曾经从微软商店装过 Python，先卸载它再装官网版，
> 否则商店版会「冒充」Python 挡住真正的 Python（详见文末 Q1b）。

### 第二步：安装项目依赖（只做一次）

1. 进入项目文件夹 `polymarket-trader`
2. 双击 **`0-install-deps.bat`**
3. 弹出小黑窗，开始自动下载安装，**等 1~3 分钟**
4. 看到下面这行就是成功：

```
[OK] all dependencies installed
Installation complete!
```

5. 按任意键关闭窗口

> 如果中途报红色错误，先确认网络正常；若是公司/校园网，可能需要代理。
> 报错信息请截图保存。

### 第三步：启动服务（每次使用）

1. 双击 **`1-start-service.bat`**（注意：不是带 `-bundled` 的那个）
2. 等约 10 秒，看到：

```
[OK] Service started: http://0.0.0.0:8765
```

3. 打开浏览器，地址栏输入：

```
http://localhost:8765
```

4. 看到界面就能用了

## 手机上用（可选）

前提：手机和电脑连**同一个 Wi-Fi**。

1. 按 `Win + R`，输入 `cmd`，回车
2. 在弹出窗口里输入 `ipconfig`，回车
3. 找到「IPv4 地址」，类似 `192.168.2.8`
4. 手机浏览器输入 `http://192.168.2.8:8765`（换成你查到的 IP）

## 怎么关闭

双击 **`2-stop-service.bat`**，或者直接关掉小黑窗。

---

## 四个文件的区别

| 文件 | 作用 | 使用频率 |
|---|---|---|
| `Python312\` | 自带的 Python 运行环境（**不要删**） | 一直保留 |
| `1-start-service-bundled.bat` | 用自带 Python 启动服务 | **每次使用（推荐）** |
| `0-install-deps.bat` | 给系统 Python 装依赖包 | 走备用路径时用一次 |
| `1-start-service.bat` | 用系统 Python 启动服务 | 走备用路径时每次用 |
| `2-stop-service.bat` | 关闭服务 | 需要关闭时 |

## 常见问题

### Q0：双击 `1-start-service.bat` 提示 `Python not found on PATH`，浏览器显示 `ERR_CONNECTION_REFUSED`

**原因**：双击了**没有** `-bundled` 的那个启动器。它走的是系统 Python，而你电脑上没装。

**现象对得上**：黑窗口显示 `[ERROR] Python not found on PATH.`，
同时浏览器 `http://localhost:8765` 报 `页面加载失败 (-102): ERR_CONNECTION_REFUSED`
（服务根本没起来，所以端口连不上）。

**解决**：关掉黑窗口，改双击 **`1-start-service-bundled.bat`**（文件名里带 `-bundled` 的那个）。
它用文件夹自带的 `Python312\`，不需要你装任何东西。

> 顺带说明：这个坑已从代码层面修掉——现在的 `1-start-service.bat`
> 会优先用自带 Python，找不到才回退系统 Python，不再直接报错退出。

### Q1：双击 `1-start-service-bundled.bat` 提示 `Bundled Python not found`

**原因**：文件夹不完整，`Python312\` 子目录没跟着一起拷贝/解压过来。

**解决**：重新完整拷贝整个 `polymarket-trader` 文件夹（包括里面的 `Python312`，它大约 48 MB、1800 多个文件）。只拷几个 `.bat` 是跑不起来的。

### Q2：小黑窗一闪就消失了

**原因**：启动过程中出错被自动关闭。

**解决**：在文件夹空白处按住 `Shift` + 右键 → 「在此处打开 PowerShell 窗口」，输入 `.\1-start-service-bundled.bat` 回车，这样报错会留在屏幕上。

### Q3：提示 `Python not found on PATH`（走备用路径时）

**原因**：安装 Python 时漏勾 `Add Python to PATH`，或没重启电脑。

**解决**（二选一）：
- 重新运行 Python 安装包 → 选 Modify → 勾上 `Add Python to PATH` → 重启电脑
- 或卸载 Python 后重新安装，第一屏就勾选

### Q3b：提示 `The "python" command on your PC is a Windows Store placeholder`

**原因**：Windows 上有一个叫「Python 3.x (Microsoft Store)」的假 Python 占位程序，
它一运行只会打开微软商店，什么也干不了。很多人是点过开始菜单里的 Python 才装上它的。

**解决**：
1. 按 `Win` 键，直接打字 `python`，如果搜索结果里有「Python 3.x (Microsoft Store)」，
   **右键 → 卸载**
2. 再打开「设置 → 应用 → 已安装的应用」，把带 "Microsoft Store" 字样的 Python 条目也删掉
3. 去 <https://www.python.org/downloads/> 装真正的 Python，第一屏勾 `Add Python to PATH`
4. **重启电脑**
5. 重新双击 `0-install-deps.bat`

> 其实**更省事的办法是别折腾**：直接用 `1-start-service-bundled.bat`，它根本不碰系统 Python。

### Q4：提示 `Dependencies missing`

**原因**：还没运行 `0-install-deps.bat`，或上次安装失败。

**解决**：先双击 `0-install-deps.bat`，看到成功提示再用 `1-start-service.bat`。
（或者干脆改用 `1-start-service-bundled.bat`，自带依赖，不需要这一步。）

### Q5：`0-install-deps.bat` 中途报错 / 下载很慢

- 确认能正常打开百度、Google 等网页
- 关闭杀毒软件/防火墙再试（有些会拦截 pip 下载）
- 公司网络可能需要配代理，可尝试：
  ```
  python -m pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
  ```

### Q6：浏览器打不开 `http://localhost:8765`

按顺序排查：
1. 小黑窗是否还开着？关了服务就停了，重新双击启动脚本
2. 地址是否写对（是 `localhost` 不是 `127.0.0.1`，端口 `:8765` 要带）
3. 换 Edge 浏览器试试
4. 防火墙弹窗是否点了「允许」

### Q7：提示 `Address already in use`（端口被占用）

双击 `2-stop-service.bat` 后再启动；或编辑启动脚本，把 `8765` 全改成 `9000`，然后访问 `http://localhost:9000`。

### Q8：界面能打开，但看不到交易数据

还没有添加要监测的钱包。进入左侧「钱包」面板，输入 Polymarket 钱包地址（`0x` 开头的 42 位字符）添加即可。

### Q9：页面一直转圈 / 提示网络错误

本程序需要访问 Polymarket 的 API。如果所在网络无法直接访问，需要在 `config.yaml` 里配置代理（见主 README「配置说明」章节）。

### Q10：Paper 模式和 Live 模式有什么区别？

- **Paper（模拟）**：不下真实订单，只记录信号和模拟盈亏，**默认就是这个，绝对安全**
- **Live（实盘）**：真实下单到 Polymarket，需要 API 凭据，涉及真实资金

新手请保持 Paper 模式，熟悉后再考虑切换。

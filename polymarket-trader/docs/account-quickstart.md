# 直接操作说明

打开 http://127.0.0.1:8765/ ，点击右上角 **配置实盘**。

## 多钱包

点击 **新增账户**，填写备注名、接入方式和实际签名地址。保存后在账户列表选中它，点击 **切换钱包**。仅在模拟盘允许切换；旧审核单和订单仍属于原账户，不会被发送到新钱包。不同账户的实盘风控状态、成交台账和平台持仓快照独立保存。

## Magic / EVM 私钥 + HMAC

1. 选择此接入方式，填写从 Magic 导出的签名私钥和实际地址。代理钱包按平台账户填写签名类型 1/2 以及 Funder；普通 EOA 使用 0。
2. 已有 API 三项凭证可以直接填写；也可以先保存私钥，再点击 **从已保存私钥生成 HMAC 凭证**。
3. 关闭账户抽屉，打开顶栏账户连接面板，点击 **检测实盘连接**。认证、可用余额和授权通过后才能启动实盘。
4. 设置跟单金额、限额、止盈止损与审核方式，再点击 **启动实盘**。后台 API 通道不要求浏览器持续在线；后端服务必须运行。

## OKX 插件

1. 在安装 OKX 插件的浏览器中打开本机地址。内置浏览器没有注入插件时会明确提示，不能代替插件。
2. 新建 OKX 账户，填写插件当前 EOA 地址，加密保存并切换到该账户。不填写私钥。
3. 点击 **连接 OKX 并授权**，插件切到 Polygon，用户确认 CLOB 认证签名。API 凭证由后端加密保存。
4. 保持页面和插件在线，检测连接后启动实盘。订单进入 **等待插件签名** 状态，打开 **配置实盘** 里的签名任务逐笔确认或拒绝。撤单另行请求用户授权签名。
5. 插件模式即使全局流程选择自动，仍需用户逐笔签名；无法无人值守。过期签名和停止实盘后的签名不会提交。

## OAuth 中继

选择 OAuth 接入方式，填写 **中继 URL（可含端口）**、EVM 地址和会话 token，例如本机地址格式 `http://127.0.0.1:9000`。远程服务必须使用 HTTPS；URL 中不能夹带 token。

中继必须实现 [账户架构文档](account-access-architecture.md) 的 `polymarket-account-bridge/1` 契约。保存 URL 不表示已连通；只有服务协议、链 137、账户地址、认证、余额与授权校验通过后才能启动。当前没有用户提供的真实 OAuth 中继，不能声称已经接通 Polymarket 的 Google OAuth 私有交易接口。

## 回执与故障

提交后后台每 5 秒调度回执核对，失败退避至最长 120 秒；平台持仓在实盘运行中每 30 秒同步。核对过程不会重发买卖订单。无法确认提交结果时保留待核对，当前账户暂停新单；可在执行记录核对订单或到平台核对。

账户抽屉显示最近执行与同步状态。同步失败保留旧快照，不以零余额或空持仓覆盖。平台持仓原始盈亏字段与本工具成交台账分别保留，不将其他来源持仓伪装成本工具收益。

凭证库位于数据库旁的 `.credentials` 文件，使用 Windows DPAPI 加密，仅当前 Windows 用户可解密。备份需同时保留数据库与加密凭证库；跨 Windows 用户直接复制不能保证解密。界面不会回显任何密钥。

自动测试使用测试密钥、模拟 SDK/中继响应；真实账户连接、成交与平台记录一致性仍需用户在实际环境验收。程序不保证盈利。

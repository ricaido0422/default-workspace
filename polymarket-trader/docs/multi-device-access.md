# 多端访问指南（PC / 手机 / 平板）

本项目是纯 Web 应用，**不需要在手机或平板上安装任何 App**。只要手机/平板和跑服务的电脑在**同一个 Wi-Fi（同一局域网）**下，用浏览器打开地址即可访问，功能与电脑端完全一致。

## 一、最快的方式：手机扫码

电脑上启动服务时**必须加 `--host 0.0.0.0`**，否则只监听 `127.0.0.1`（仅本机可达），手机会连不上：

```bash
python run.py --host 0.0.0.0            # 标准启动
python run_minimal.py --host 0.0.0.0     # 降级启动
```

启动成功后，手机浏览器输入：

```
http://192.168.2.8:8765
```

> 上面的 `192.168.2.8` 是这台电脑当前的局域网 IP。如果 IP 变了（重连 Wi-Fi、换网络），用下面的命令重新查。
>
> `run_minimal.py` 在绑定 `0.0.0.0` 时会额外打印一行 `📱 局域网访问：用手机浏览器打开 http://<本机局域网IP>:8765`，可按提示操作。

## 二、查询本机 IP

**Windows（PowerShell）**
```powershell
ipconfig
```
找「IPv4 地址」，通常是 `192.168.x.x` 或 `10.x.x.x`。

**Mac / Linux**
```bash
ifconfig | grep "inet " | grep -v 127.0.0.1
```

## 三、手机打不开？按顺序排查

| 现象 | 原因 | 解决 |
|---|---|---|
| 一直转圈 / 无法访问 | Windows 防火墙拦了 8765 端口 | 见下方「开放防火墙端口」 |
| 一直转圈 / 无法访问 | 服务只绑定了 `127.0.0.1` | 启动命令加 `--host 0.0.0.0` 重启 |
| 能打开但实时数据不动 | WebSocket 被拦或用了 `run_minimal.py` | 用 `run.py` 启动（`run_minimal.py` 不支持 WS） |
| 显示 localhost / 127.0.0.1 | 手机把 localhost 解析成它自己 | 地址必须写电脑的局域网 IP，不能用 localhost |
| 电脑能开、手机不能 | 两者不在同一 Wi-Fi（如电脑插网线、手机用流量） | 统一到同一局域网；或走「四、公网访问」 |
| 电脑本地也打不开 | 服务进程已退出 | 看终端有无报错；若服务是临时启动的，确认它仍在运行 |

### 确认服务真的在监听所有网卡

```powershell
netstat -ano | findstr 8765
```

应看到 `0.0.0.0:8765` 或 `<局域网IP>:8765` 且状态为 `LISTENING`。
若只看到 `127.0.0.1:8765`，说明没有绑定成功，检查启动命令的 `--host` 参数。

### 开放防火墙端口（Windows）

以**管理员身份**打开 PowerShell，执行：

```powershell
New-NetFirewallRule -DisplayName "Polymarket Trader 8765" `
  -Direction Inbound -Protocol TCP -LocalPort 8765 -Action Allow
```

## 四、不在同一网络时（外出用手机看）

三种方案，按推荐顺序：

1. **内网穿透（最省事）**：在电脑上跑 `ngrok http 8765` 或 `cloudflared tunnel --url http://localhost:8765`，把生成的公网域名填到手机浏览器。注意这是**无认证暴露**，谁拿到域名都能操作你的跟单配置。
2. **VPN / 组网**：Tailscale、ZeroTier 等，把手机和电脑编到同一虚拟内网，安全性最好。
3. **云服务器部署**：用项目自带的 Docker（`docker compose up -d --build`），部署到有公网 IP 的 VPS。此时**务必自行加一层反向代理认证**（如 Nginx Basic Auth 或 Authelia），因为应用本身没有登录鉴权。

> ⚠️ 当前版本**没有用户登录与权限系统**，所有能访问到服务的人都拥有完整操作权限（包括切换 Live 实盘模式、修改风控参数、删除钱包）。仅在可信网络内使用，或在外网暴露前自行加网关层认证。

## 五、移动端适配情况

- 前端已做响应式：`index.html` 含 viewport meta，`style.css` 有针对 `≤1024px` / `≤768px` 两档断点，窄屏下侧边栏收缩为图标条、统计卡改两列
- 10 个面板均可正常使用；表格类面板（交易列表、执行记录）在窄屏下横向滚动
- WebSocket 推送在手机上同样生效，实时性取决于网络质量

## 六、Docker 部署时的访问

`docker-compose.yml` 已映射端口，容器内外都是 `8765`。局域网内其他设备访问：

```
http://<跑 Docker 那台机器的局域网 IP>:8765
```

## 七、实测记录（2026-10-24）

在本机（Windows，局域网 IP `192.168.2.8`）实测通过：

| 验证项 | 结果 |
|---|---|
| `--host 0.0.0.0` 绑定后 `127.0.0.1:8765` | ✅ 200 |
| 同一服务通过 `192.168.2.8:8765` 访问 | ✅ 200 |
| 局域网 IP 下 20 个 GET 端点 | ✅ 20/20 |
| 局域网 IP 下 7 个静态资源（含新增面板 JS） | ✅ 7/7 |
| 局域网 IP 下 `PUT /api/portfolio` | ✅ 200 |
| 局域网 IP 下 `POST /api/portfolio/check` | ✅ 200，权重分配与风控上限均正确 |

**踩坑记录**：`run_minimal.py` 早期版本只读环境变量 `PM_HOST`、默认 `127.0.0.1`，传入的 `--host 0.0.0.0` 被静默忽略，导致局域网设备连不上。已修复为与 `run.py` 一致的 argparse 参数，并增加绑定成功后的局域网提示。

## 八、添加到手机主屏幕（可选）

在手机浏览器打开地址后：

- **iOS Safari**：分享 → 「添加到主屏幕」
- **Android Chrome**：右上角菜单 → 「添加到主屏幕」/「安装应用」

之后就像 App 一样全屏打开。

# 智能策略交易

打开 http://127.0.0.1:8765/#smart 。当前服务默认模拟盘，模板不会自动启用。

## 使用

1. 选择趋势动量、回调反弹、大额钱包跟随、多钱包共识或大模型筛选。
2. 从平台近期成交选择市场，或填写真实 Token ID。钱包相关策略必须填写白名单；共识要求足够多的不同钱包。
3. 设置金额、每日委托预算、入场冷却、观察窗口、止盈和止损。选择自动执行或半自动审核，勾选启用并保存。
4. 自动策略走同一个交易台：盘口、信号时效、最小数量、余额、全局损失和仓位限额全部保留。全局“仅观察”会阻止自动下单。
5. 持仓每10秒独立检查买盘退出，不依赖来源钱包继续成交。止损卖出不受入场冷却、入场次数和模型否决限制；仍需真实流动性与可卖份额。断网、跳价或深度不足不能保证按止损价格成交。
6. “暂停全部智能策略”停止新信号与未提交审核单，也停止这些策略的自动退出；已有仓位和已提交订单不会被自动抹掉。修改参数后旧审核单失效。

策略绑定模拟/实盘模式及交易账户。实盘必须先完成原有账户自检并由用户启动，策略保存不能自行切换实盘。OKX 插件仍需逐笔签名，自动策略不会绕过钱包确认。

## 接入大模型

在页面下方配置兼容 Chat Completions 的服务根地址、模型名、API Key、每日调用上限。根地址示例格式为 `https://你的服务商/v1`，本机服务支持 `http://127.0.0.1:端口/v1`。不要求特定服务商。

Key 使用 Windows DPAPI 加密，不回显、不落入公开配置。切换服务地址会清除旧密钥，避免发送给另一服务商。测试连接消耗一次请求，但不产生委托。

模型只收到公开标题、标的和最多20笔成交价格/方向/数量；没有新闻检索或独立真实概率依据，不发送私钥、账户余额。它只能返回 approve / skip、置信度与简短原因，不能修改金额、价格、账户或风控。非法字段、超时、接口失败、置信度不足和预算耗尽均跳过，不降级为无模型自动买入。止损退出不依赖模型批准。

请求最多240输出 tokens、默认12秒超时、全局最多每30秒一次；每日请求预算包含连接测试、否决和失败。没有用户实际接口及密钥时，真实模型供应商连接尚未验收；测试使用本地 HTTP Mock 契约。

## 产出测算

默认模板按每笔10 USDC、每月20笔、往返交易成本2.5%测算，模型成本默认未计。下表只是不同假设胜率下的月净额，不是实测策略表现或未来收益预测。

| 模板 | 止盈 / 止损 | 假设35%胜率 | 假设50%胜率 | 假设65%胜率 |
|---|---|---:|---:|---:|
| 趋势动量 | 12% / 8% | -7.00 | -1.00 | +5.00 |
| 回调反弹 | 10% / 7% | -7.10 | -2.00 | +3.10 |
| 大额钱包跟随 | 15% / 10% | -7.50 | 0.00 | +7.50 |
| 多钱包共识 | 15% / 8% | -4.90 | +2.00 | +8.90 |
| 大模型筛选 | 12% / 8% | -7.00 | -1.00 | +5.00 |

公式：月净额 = 单笔金额 × 假设月交易数 × [假设胜率 × 止盈比例 − (1−假设胜率) × 止损比例 − 假设往返成本率] − 每次模型费用 × 假设月模型调用数。未启用模型时模型费用为零。调用数应计入失败、否决的请求；不会把服务商调用费用假装成零成本。

按1000 USDC 资金给出情景回报率，不采用复利。实际次数、胜率、滑点和退出价格未知；止损失败时单笔最大损失可能达到全部投入。不同模板数字差异来自止盈止损假设，不是证明某种策略更有效。

实际模拟成交按 FIFO 归因，计入设置费率估算成本；至少20笔平仓才显示历史胜率和 bootstrap 历史均值区间。样本可能相关，这不是未来收益置信承诺，也不是经过样本外验证的胜率。更改参数会改变策略分布，不能用旧样本保证新参数效果。

# 跟单工作台范围

先提供 copy-workbench-preview.png，再按同一结构实现；参考 CopyOdds 公共页面加载的榜单、跟单管理、模拟模式和金额配置文案。

- 发现交易员：官方区间榜单＋本地观察钱包，搜索及人工板块标签筛选。
- 快捷配置：固定金额/份额比例、单笔上限、最小源金额、买入价格区间、跟随卖出。
- 我的跟单：编辑、暂停、恢复；暂停和修改作废旧审核单，只接收创建/恢复后的成交。
- 规则绑定 PAPER/LIVE，沿用交易台风控与审核。同模式资金与止盈止损共享。
- 卖出额度保守取本规则净买入份额、全局 FIFO 剩余归属和工具总持仓的可用量；多规则交叉减仓后可能需手动处理余仓。
- 参考站托管、奖励和聊天功能不在此轮范围。无完整成本数据不推断胜率。
- 原有高级策略保留，避免和快捷规则对同一钱包重复跟单。

实现入口：frontend/js/panels/copy-hub.js，backend/core/copy_rules.py，backend/api/desk_routes.py。

策略参数

改完点「保存参数」，下一轮轮询自动生效，不需要重启。但下面这些改动会让机器人自动重启并清零累计账目：跟单对象、下单金额、仓位上限。

跟单对象

当前默认 ColdBlooded：胜率 69%，盈亏比 1.79，低频高信念型。

下单金额

fixed 只用「每笔金额」。
percent = 对方下 $1000、比例 2% → 你下 $20（跟得更忠实，本金小容易低于 $1 失败）。
balancePercent = 用剩余可用余额的比例，赚了自动加大、亏了自动缩小（上限 50%）。

资金区间过滤

当前不设上限的理由：他出手少，大单往往是最强信号，设上限会砍掉最值钱的下注。

板块 / 赛事过滤

英文逗号分隔，大小写随便，空格写法等价连字符（league of legends = league-of-legends）。
三级粒度任选：板块 esports · 赛事 league-of-legends / dota-2 · 阶段（区间） lol-worlds-2026 / swiss-round-2。
不知道填什么 → 去下面「交易员分析中心 → 板块过滤」点「扫描他的板块」，那里会列出他真实打过的板块，点一下就填进来。

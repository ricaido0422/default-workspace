> 项目根目录：`D:\Users\Administrator\Documents\deepseek-harness\default-workspace\.dsh-switchman\probe-npm`

## 0. 一句话定位

这是一个 **30 USDC 起步、DRY-RUN 优先、配置文件驱动** 的 Polymarket 跟单机器人。核心诉求是「稳妥高胜率」，重心放在**操作完善 + 自动执行**（断电能保住账、到线自动停、失败自动退避），**不是**堆功能。

## 3. 设计决策（复审时请确认这些取舍是否合理）

| 决策点 | 选择 | 理由 |
|---|---|---|
| 跟单对象 | ColdBlooded `0xbcc…9c`（69% / PF 1.79 / 低频高信念） | 胜率稀缺；低频高信念型信号干净 |
| 下单方式 | fixed $3/笔 | 本金仅 $30，percent 模式单笔易低于 $1 最小下单额而全败 |
| 资金上限 `maxTradeUsd` | 暂设 `0`（不设上限） | ColdBlooded 大单=最优信号，设上限反砍最有价值的单。**换跟单对象要重评** |
| 市场成交量下限 | 实测 LoL 盘仅 $36K，但 ColdBlooded 押 $3481 在此盘 → 若设 $50K 会全跳过 | 建议改 `$20000` 或 `0`，**当前 config 仍是 50000，属待用户决的待办** |
| 止损/止盈 | -$9 / +$15 | 本金 30% 止损、翻倍止盈落袋 |
| 单日熔断 | $5/天，次日自动恢复 | 防「今天手气背」 |
| `autoFlattenOnStop` | 默认 `false` | 冷门盘市价清仓滑点可能比止损线还大，放着等结算更划算 |
| 模式切换 | 网页大按钮 + 手输 `CONFIRM` + 三道前置条件 | 唯一「点错就亏真钱」的动作，要多道摩擦 |
| 状态落盘 | `logs/console-state.json`（每变更即写） | 断电/重启不重复跟单、仓位上限不失效 |
| 失败退避 | 60s→2x→…→900s 封顶，连续 6 次停机 | 代理断时不无限撞墙 |
| 安全 | 私钥只存本机、日志/网页全打码、只听 127.0.0.1、跨站拦截 | 钱包安全底线 |
| 数据可信 | 战绩只从 `/closed-positions`（已平仓 realizedPnl）算 | `/positions` 是浮亏、平台标称值不可信 |

## 4. 已知问题 / 待办（复审重点）

1. **`minMarketVolumeUsd: 50000` 大概率要调低**：ColdBlooded 最好的几笔全在 $36K 成交量盘上，按 50000 会全部 `DIM` 跳过。建议 20000 或 0。（已在 config 注释里写，等用户拍板）
2. **跟单对象待换**：用户明确说「跟单对象以后重新设置」。Smallcoins（79%/PF 5.76/1855笔）统计优于 ColdBlooded，但下单极快极碎，$30 本金跟不上——本金量级不匹配，不是代码问题。
3. **`funderAddress` 实际只有 39 位**（`0x1279333686e1766Efc417acD55547E772EA7328` 漏了末位，用户从交易所复制漏的）。代码已放宽到 `0x[0-9a-fA-F]{39,40}`，切 LIVE 不会卡；但 `targetWallet` 仍严格 40 位（防跟错人）。
4. **`legacy\2-开始监控.bat`（src/index.mjs）是旧入口**：无退避、无熔断、不落盘到 console-state.json。README 已标注「要自动执行请用网页控制台」。
5. **模式开关 / React 式前端无单元测试**：app.js 的交互逻辑靠人工+截图验证，没有 test 覆盖（这是前端，不是核心风险逻辑）。
6. **USDC 余额查询依赖 Base 公共 RPC**：`https://mainnet.base.org`，慢可换付费节点。
7. **HomeRunHazard 已被排除**：胜率 51%（随机水平）、PF 1.05、611 个并发持仓、45775 市场全品类撒网——无法复制。

## 5. 安全红线（复审时务必验证没有被破坏）

- 私钥 `0x`+64位 在 `util.mjs` 和 `guard.mjs` 两处独立打码，正则一致（`/0[xX][0-9a-fA-F]{64}/g`）。测试 `_test_guard.mjs` 覆盖大小写/日志/多密钥。
- 跨站：`assertSameOrigin` 只信 `Origin` 头（浏览器强制带、不可 JS 伪造）+ 强制 `application/json`。测试覆盖跨站拒、无 Origin+json 放行。
- 自跟单：`targetWallet === funderAddress` 直接拒启动。
- 单笔上限 > 总仓位 50% 拒启动（`assertSafeConfig`）。
- 真实下单只在 `mode=live` 且 `trader.mjs` 被懒加载时才有；dry-run 零第三方依赖。

## 6. 环境踩坑记录（给复审模型的背景，避免重蹈覆辙）

- **本机直连 Polymarket 超时**：必须走本地代理 + `NODE_USE_ENV_PROXY=1`（Node v26 的 fetch 只在进程启动读一次代理配置，运行期改 `process.env` 无效 → 所以 `proxy.mjs` 用 `spawnSync` 重启自身带环境变量）。
- **Windows PowerShell 改中文文件会损毁**：`Get-Content -Raw | Set-Content -Encoding utf8` 会把 UTF-8 字节按 GBK 读再按 UTF-8 写，全中文变 mojibake（已发生过一次 README 全毁，已用 `write` 工具重写修复）。**一律用 Node fs 或 read/edit/write 工具改中文文件。**
- **bash 沙箱在本机会崩溃**（`CreateFileMapping Win32 error 5` / `EXECUTOR_UNAVAILABLE`）：用 `pwsh` 代替 bash。
- **跨轮 read 记录失效**：另一个模型/另一轮读过的文件，edit 前要重新 read，否则报 `file has not been read`。

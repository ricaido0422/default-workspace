# Polymarket 跟单控制台 — 使用教程

> 从零开始，一步一步照着做。全程约 2 分钟。

---

## 第一步：双击启动

打开文件夹 `polymarket-follow`，找到这个文件：

```
启动UI.bat
```

**双击它。**

会弹出一个黑色命令行窗口，显示下面这些字，然后你的浏览器会自动打开控制台：

```
============================================================
  Polymarket Copy-Trading Console - Launcher
============================================================

[1/3] Found DSH bundled Python
[2/3] Port 8791 is free, starting...

[3/3] Started! Your browser should open automatically.

 ============================================================
   Console URL:  http://127.0.0.1:8791
   Closing this black window STOPS the copy-trading
   Do NOT close it, or you will lose the signal feed
 ============================================================

==============================================================
Polymarket 跟单控制台
==============================================================
  地址:     http://127.0.0.1:8791
  代理:     http://127.0.0.1:7897
  跟单钱包: 2 个
  执行器:   未启用（dry_run=True）
  最小跟单: $6000
==============================================================
```

**⚠️ 这个黑色窗口不要关！** 关掉 = 停止跟单，你就看不到信号了。

> 后面那几行中文显示成乱码是正常的，不影响使用，只是 cmd 默认编码问题。

---

## 第二步：确认梯子开着

控制台要翻墙才能连上 Polymarket。打开你的 Clash / 梯子软件，确认它在运行（端口 7897）。

验证方法：点控制台上的 **「🔍 立即自检」** 按钮。

- 三个接口都显示 **✓ 通** → 网络没问题，继续
- 有 **✗ 断** → 梯子没开，或者端口不是 7897，回去检查梯子

---

## 第三步：点「开始跟单监测」

控制台最上面有一排蓝色/红色按钮，点第一个：

```
▶ 开始跟单监测
```

点完之后：

- 左上角的小圆点从红色变成 **绿色**，显示「运行中」
- 左边「📡 实时信号流」开始滚动出内容
- 每 1 秒自动刷新一次

---

## 第四步：看懂信号流

信号流里每一条长这样：

```
19:31:22  [重仓] 新开仓 · Will Arsenal win the 2026-27 EPL Championship?
          BUY Yes | 数量 400000.00 | 价值 $266,000.00 | 价格 0.665
```

| 标签 | 含义 |
|------|------|
| 🟡 **重仓** | 大佬这笔 ≥ 6000 美元，值得关注 |
| ⚪ **小额** | 大佬这笔 < 6000 美元，只是记录，不会提醒你 |
| 🟣 **跟单** | 真的下单了（现在执行器关着，永远不会有） |
| 🟠 **监测** | 市场价格异动（价差变大、没流动性等） |
| 🔴 **错误** | 网络或接口出问题，看 detail 里的说明 |
| 🔵 **系统** | 启动、停止、配置保存等操作记录 |

| 动作类型 | 含义 |
|------|------|
| **新开仓** | 大佬刚买入一个新方向 ← 最该跟的 |
| **加仓** | 大佬在原有仓位上继续加码 ← 也可以跟 |
| **减仓** | 大佬在卖出一部分 ← 参考，别急着动 |
| **平仓** | 大佬全撤了 ← 重要信号，你可能也该撤 |
| **新成交** | 大佬的一笔具体成交记录 |

## 第五步：调整参数（可选）

控制台往下拉，找到 **「⚙️ 风控与过滤参数」**，改完点 **「💾 保存配置」**：

| 参数 | 现在的值 | 什么意思 |
|------|------|------|
| 最小跟单金额 | 6000 | 大佬这笔低于 6000 美元就不理（过滤噪音） |
| 单笔上限 | 2 | 你自己每笔最多花 2 美元 |
| 每日上限 | 5 | 一天最多花 5 美元 |
| 跟单比例 | 0.01 | 大佬买 1 万美元，你买 100 美元 |
| 买入价下限 | 0.02 | 低于 2 分的彩票单不碰 |
| 买入价上限 | 0.98 | 高于 98 分的稳单不碰（没利润） |
| 轮询间隔 | 1 秒 | 每 1 秒查一次大佬动静 |
| 滑点容忍 | 0.02 | 价格比你看到的高 2% 以内还能接受 |

> 这些参数现在只是"预设值"，因为**执行器是关的，不会真的下单**。
> 改它们是为了以后开执行器时直接用，或者你自己手动照着下单。

## 常用操作速查

| 你想干什么 | 点什么 |
|------|------|
| 马上看一次大佬持仓 | **⚡ 手动跑一轮** |
| 检查网络通不通 | **🔍 立即自检** |
| 暂停 | **⏸ 停止** |
| 重新开始 | **▶ 开始跟单监测** |
| 改参数 | 表单改数字 → **💾 保存配置** |

---

## 顶部的数字卡片是什么意思

| 卡片 | 含义 |
|------|------|
| 今日信号 | 今天一共出现多少个信号（含小额） |
| 重仓信号 | 其中 ≥6000 美元的有几个 |
| 已跟单 | 真正下单成功的数量（执行器关着就是 0） |
| 风控拒绝 | 因为超限额被拦下的数量 |
| 跟单大佬 | 在盯几个钱包（现在 2 个） |
| 监测市场 | 在盯几个市场的价格异动 |
| 今日已用额度 | 今天已经花了多少钱（上限 5 美元） |
| 运行时长 | 这次连续跑了多久 |

## 出问题了怎么办

### 小黑框一闪而过、什么都没看到

说明启动脚本报错退出了。打开文件资源管理器，进到 `polymarket-follow` 文件夹，**地址栏输入 `cmd` 回车**，会弹出命令行窗口，然后输入：

```
启动UI.bat
```

这样窗口不会关，你能看到具体卡在哪一行。

### 浏览器打不开 / 显示无法访问

1. 看那个黑色窗口还在不在——关了就打不开
2. 窗口里有没有报错
3. 手动在浏览器地址栏输入：`http://127.0.0.1:8791`

### 提示「8791 端口已被占用」

说明之前已经启动过一次。**直接去浏览器开 `http://127.0.0.1:8791`** 就行，不用再启动。

### 自检显示 ✗ 断

- 梯子没开 → 打开 Clash
- 梯子端口不是 7897 → 用记事本打开 [config.json](config.json)，把 `"proxy"` 改成你自己的端口

### 信号流一直空着

- 大佬这会儿没动静（正常，他们在睡觉）
- 点 **⚡ 手动跑一轮** 强制拉一次
- 还是空就看有没有 🔴 错误条目

## 你现在看到的是「安全模式」

**执行器是关闭的**（`executor.enabled = false`），意思是：

✅ 能看到大佬在干什么
✅ 能收到信号、能看到价格
❌ 不会用你一分钱
❌ 不会真下单

这是最安全的状态。要真跟单，必须满足三件事：

1. 在 `config.json` 里把 `executor.enabled` 改成 `true`
2. 配置 OKX 钱包私钥和 Polymarket 代理钱包地址
3. 补装 `py-clob-client` 下单库

**这三步我都不建议你现在做**——10U 本金，单笔最多 2U，一天下来盈亏就在 ±0.5U 以内，不够手续费折腾的。先看着，熟悉了再说。

## 文件都在哪

```
polymarket-follow/
├── 启动UI.bat      ← 双击这个
├── ui.py           ← 控制台程序（不用管）
├── config.json     ← 配置文件
├── main.py         ← 命令行版（有 UI 就不用它了）
├── state.json      ← 运行状态（自动生成，别手动改）
└── pmfollow/       ← 核心代码（不用管）
```

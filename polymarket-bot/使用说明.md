## 🔑 config.yaml 凭据（你需要填）

```yaml
bot:
  private_key: "你的私钥"           # ← 从 OKX Wallet 导出，64 位 hex，无 0x 前缀
  funder_address: "0x你的地址"      # ← 你的 OKX Wallet Polygon 地址
  # L2 凭据留空，启动时自动派生
```

**如何获取：**
- **private_key**：OKX Wallet 插件 → 钱包管理 → 当前钱包 ⋮ → 查看私钥 → 输密码 → 复制
- **funder_address**：OKX Wallet 切 Polygon 网络 → 顶部地址（= polymarket.com → Deposit 页地址）

## ⚙️ config.json 关键设置

| 段 | 关键字段 | 说明 |
|----|---------|------|
| bot | enable_trading | false=空跑（默认），true=实盘 |
| bot | wallets_to_track | 跟单对象钱包地址数组（默认是示例地址，需替换） |
| strategy | copy_size | 跟单比例，首次实盘建议 5–10 |
| strategy | max_order_size_usd | 单笔上限（默认 500） |
| site | polygon_ws_url | Polygon WebSocket 端点（需换成 Alchemy） |
| site | polygon_rpc_url | Polygon RPC 端点（需换成 Alchemy） |
| risk | — | 熔断器：30 秒内 2 笔大额即触发，冷却 120 秒 |
| filters | — | 默认只跟 Politics/Sports/Crypto，屏蔽 Memes |
| tp_sl | — | 止盈止损默认开启（止盈 50%/止损 30%） |

## 🚀 从零到实盘（6 步）

### 1. 注册 Polymarket + 准备钱包
用 OKX Wallet 插件连接 polymarket.com 登录。建议为机器人单独建一个 OKX Wallet 账户，只放测试资金。

### 2. 填凭据（config.yaml）
导出私钥填 `private_key`，复制地址填 `funder_address`。**私钥永不分享。**

### 3. 充值
向你的地址发送 USDC（**Polygon 网络**）+ 少量 POL（gas 费，几美元）。
从 OKX 交易所提币：选 USDC → 网络选 **Polygon**（不是 Base/ERC-20）→ 填你的地址。

### 4. 配置 Polygon RPC
注册 alchemy.com → 创建 Polygon Mainnet 应用 → 获取 API key，填入 config.json：
- `site.polygon_rpc_url` = `https://polygon-mainnet.g.alchemy.com/v2/<KEY>`
- `site.polygon_ws_url` = `wss://polygon-mainnet.g.alchemy.com/v2/<KEY>`

### 5. 选跟单对象
在 polymarket.com 找战绩好的交易者，复制其钱包地址，填入 `bot.wallets_to_track`。

### 6. 空跑 → 实盘
- 先保持 `enable_trading: false`，双击 `启动-空跑.bat` 观察一整轮
- 确认正常后，改 `enable_trading: true` 开实盘

## ▶️ 启动方法

**空跑（不下单）**：双击 `启动-空跑.bat`（需先开梯子）

**TUI 交互模式**：双击 `启动-TUI交互模式.bat`

**命令行**：
```
启动-空跑.bat        REM 或直接：polymarket-toolkits.exe run copy-trading
polymarket-toolkits.exe --help    REM 查看帮助
```

## ⚠️ 安全红线

1. **私钥永不分享、永不提交 git**（config.yaml 已在 .gitignore）
2. 先用小资金 + `enable_trading: false` 充分测试
3. 用专用钱包，只放计划部署的资金
4. Polymarket 有地区限制，需全程挂梯子
5. 预测市场交易涉及真实财务风险，本工具按「原样」提供，不构成投资建议
